# Mini Blockchain

A simple blockchain implementation in Python.

## Project Overview

This project demonstrates the basic concepts behind blockchain technology:

- Blocks
- Transactions
- SHA-256 hashing
- Previous block hash
- Genesis block
- Proof of Work
- Nonce
- Blockchain validation
- Tamper detection
