# Blockchain Voting DApp

A decentralized voting application built using Solidity, Ethereum Sepolia Testnet, MetaMask, and Ethers.js.

## Features

- Connect MetaMask wallet
- Vote only once per wallet
- View election winner
- Smart contract deployed on Sepolia
- Responsive frontend using HTML, CSS, and JavaScript

## Technologies Used

- Solidity
- Remix IDE
- MetaMask
- Ethereum Sepolia Testnet
- Ethers.js
- HTML
- CSS
- JavaScript

## Smart Contract Functions

- addCandidate()
- vote()
- getWinner()
- getCandidate()
- candidatesCount()

## How to Run

1. Clone the repository.
2. Open `index.html` using Live Server.
3. Connect MetaMask.
4. Ensure MetaMask is on the Sepolia network.
5. Vote and view the winner.
